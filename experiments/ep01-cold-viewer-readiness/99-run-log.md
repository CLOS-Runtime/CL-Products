## Method notes (recorded before evaluator runs)

1. **Instrument freeze.** `00-frozen-instrument.md` written before any evaluative reading; sha256 `42d084ec4da1ce85e637ff527dcd8ebeb98025b10ab55c2028c018e8affd85b0`, frozen 2026-08-10T01:45:27Z. The input script arrived in the same message as the experiment brief, so orchestrator-level literal blindness is impossible; the instrument was built generically from the brief's criterion list and has not been edited since freezing (hash verifiable).
2. **Contamination control.** No repository content, history, prior scripts, prior audits, or other Calculated Landlord material was read at any point. The only repository operations are: creating a new branch, adding NEW experiment-output files, committing, pushing. No existing artifact is read or altered.
3. **Evaluator independence.** Seven evaluators run as separate agent contexts. None sees another's output. Each receives: its viewing condition, protocol rules, the production assumption, and script segments one at a time across eight sequential messages. Criterion anchors and label definitions arrive only at the final step (frozen decision, instrument §0).
4. **Sequential exposure.** True multi-turn exposure: at each checkpoint the evaluator's context contains only the segments seen so far. Later text physically absent at answer time — checkpoint answers cannot be contaminated by later material.
5. **Segment boundaries.** 150 wpm nominal. CP2 boundary placed at the natural structural seam "…we gave the idea five ways to fail." (~1:22 at 150 wpm; within the brief's "approximately 1:30", per instrument §1 allowance; recorded here). CP3 boundary ends exactly at the −$90 reveal beat ("…on our own planning assumptions.") before any subsequent text, per the brief. The remainder of check one (tax/insurance caveat, rent sensitivity, yellow verdict) therefore rides at the head of Segment 4 with checks two and three.
6. **Recall limitation.** Evaluator agents retain conversation context; literal forgetting cannot be enforced. The recall phase is administered without re-showing text, instructs answering from immediate impression, and requires flagging anything only reconstructable-by-reasoning as PARTIAL/LOST. Reported with this caveat (frozen in instrument §0).
7. **Word counts / timing** (verified with wc below): recorded after transcription.
8. **Adversary and season-arc evaluators** are fresh contexts instantiated only after the seven cold-viewer runs complete. Adversary receives script + passage IDs only, not viewer outputs.
